单物体流水线 v0.8 修订

v0.7 实测的三个样本暴露出同一个缺陷：流水线只记录了"哪里有表面"，没有记录"哪里确定是空的"。所以它分不清真实的开口和被遮挡造成的空洞，也无法验证模板加了不该有的结构。本次修订引入空间三态证据（占据、空、未知），让补全、拟合和质检都建立在它上面，并为躺椅这类没有模板的物体换一条天然水密的重建路线。

圆凳：模板凭空加了结构底部的嵌入圆板没有任何观测证据支持，而侧壁贴地的观测反而没有被模型覆盖。修订后，模型必须覆盖所有占据证据，接触面只能是侧壁延伸到地面后封平。
H 底座桌：真开口被当成空洞补上开口处光线穿过去打到了地面，这是"确定为空"的证据。修订后模型不允许占据确定为空的空间，残差区域自动转成布尔切割。遥控器按支撑面异物剔除。
躺椅：兜底路线失效、门禁没拦住可信点太稀疏，泊松加裁剪留下大量洞，而且带洞的 mesh 直接输出了。修订后改用剖面扫掠或体素雕刻，天然水密；水密检查改为硬门禁。

01三个样本复盘

以下"直接原因"是根据截图推断的，每一条都给出了确认方法，对应第 09 节的实验。

样本现象可能的直接原因暴露的方案缺陷
圆凳（软包圆墩）底部多出一块内缩的圆板，近地面一段的轮廓和原高斯不一致① 选了带底座或带腿的模板，这类物体其实就是一个实心圆柱；② 裁剪地面以下高斯时余量太大，侧壁最下面几厘米被删掉，模型高度拟合偏短，封口再补出一块小圆板；③ 贴地处阴影很重，被当成另一种材质或另一个部件没有检查模型是否覆盖了全部占据证据；模板可以加入没有观测支持的部件；接触面封口没有规定形式
H 底座桌桌面右上角的开口被补平；遥控器没剔除干净，桌面上留下黑块和鼓包① 矩形桌面模板没有"缺口"这个参数，全局轮廓 IoU 对小缺口不敏感，门禁照样通过；② 遥控器的高斯在分割时归到了桌子，拟合和取色都用了它"缺失"和"确定为空"没有区分；没有残差特征编辑；没有支撑面异物检测
躺椅几何没有修复，表面布满孔洞没有匹配的模板，走了兜底路线 D；可信点稀疏，Screened Poisson 之后按密度裁剪掉了大量面片；小洞填充只处理了很小的洞兜底路线本身不保证水密；水密门禁没有强制执行，失败结果流到了输出
共同的根因v0.7 的置信度只给"观测到的表面点"打分，空间里其余位置都当作"不知道"。可是有些空间其实是知道的：相机的光线穿过去，打到了更远处的地面或墙面，那段路径上就确定没有东西。缺了这类证据，流水线分不清"桌角本来就有缺口"和"桌角被挡住了"，也无法发现"模型在不该有东西的地方多出了一块"。

02空间三态证据

做法和机器人建图里的占据栅格（occupancy grid）相同。在物体包围盒外扩 5 cm 的范围内建体素网格，体素边长 5 mm（一张 0.6 m 的桌子约 130³ 个体素，用 GPU 张量计算很快）。每个体素标成三种状态之一。

计算方法

每个视角各渲染两次：一次只渲染物体高斯，一次渲染整个场景的高斯（物体也在里面）。场景渲染决定光线停在哪里，物体渲染决定停下的位置是不是物体本身。

for 每个视角 v（仅限可信相机区域，见下）:
    D_scene, A_scene = render(全场景高斯, v)      # 光线在场景中实际停下的深度
    D_obj,   A_obj   = render(物体高斯, v)
    for 每个体素 x:  p, z = 投影(x, v)
        if A_scene[p] < 0.95: continue                       # 场景渲染本身不可信
        if z < D_scene[p] - δ:          free[x] += w_v          # 光线穿过 x 后才停下：x 为空
        elif |z - D_scene[p]| <= δ and A_obj[p] > 0.95 and |D_obj[p] - D_scene[p]| <= δ:
                                         occ[x]  += w_v          # 光线停在 x，且停下的是物体
        # z > D_scene + δ：x 在可见表面后方，这个视角不提供信息

state[x] = 空    if free[x] >= 3 且 occ[x] == 0
         = 占据  if occ[x]  >= 2
         = 未知  其余
  • δ 取 1.5 个体素；w_v 取入射角余弦。
  • 可信相机区域。虚拟相机只放在真实采集时人或机器人可能到达的位置：离地 0.4–2.0 m，在其他物体外部，离物体 0.5–3 m。真实采集从未到过的角度，场景高斯渲染出来的内容本身可能是伪造的，用它判定"空"会出错。贴地的底面因此大多是未知，由接触面规则处理（第 04 节）。
  • 阈值要求多个视角同意。空需要至少 3 个视角，用来抵消场景里个别漂浮高斯带来的错误判断。

对称：在体素空间里补未知

v0.7 的对称投票在表面点上做，实现复杂，对对称轴误差也敏感。改为在体素上做：对于有对称性的物体，一个未知体素如果它的对称副本有确定状态，就取副本的状态。空和占据都会传播，所以对称的缺口和对称的实体都能补对。只有所有对称副本都未知的体素才留给模板或先验去决定。

03形状构造三条约束

不管走哪条补全路线，最终的实体 S 都必须满足下面三条。这三条也是拟合目标函数的主体，以及 G4 门禁的核心指标。

约束含义解决的问题
覆盖占据占据体素必须在 S 内部或表面上圆凳侧壁贴地一段没被覆盖；模型尺寸拟合偏小
排除空S 不能包含空体素桌角开口被补平；模板凭空长出部件
未知由先验决定未知体素按对称、接触面规则、模板或平滑性来决定遮挡区域、底面、背面

参数拟合目标函数（替换 v0.7 第 09 节）

L(θ) = w1 · |占据 \ S(θ)|                     # 没覆盖到的占据体素数
     + w2 · |空 ∩ S(θ)|                       # 侵占的空体素数
     + w3 · Σ_可信点 conf_p · ρ(dist(p, ∂S(θ)))   # 表面贴合，同 v0.7
     + w4 · R(θ)                              # 先验正则
建议初值：w1 = w2 = 1（按体素计），w3 使表面项与体素项量级相当

S(θ) 的体素化用 trimesh 的 contains 或 Open3D 的 RaycastingScene.compute_occupancy，每次评估在毫秒到几十毫秒量级，CMA-ES 完全够用。

拟合后的残差就是诊断信息

  • 空 ∩ S 残差成团：模型多了东西，比如漏掉的缺口、开孔，或者模板加了不该有的部件。处理：特征切割（第 05 节）或更换模板。
  • 占据 \ S 残差成团：模型少了东西，比如漏掉的部件或尺寸偏小。如果残差落在支撑面上方，先按异物检查（第 05 节）。
  • 残差团用 6 连通分量提取，体积小于 2 cm³ 的忽略。

04圆凳：接触面与底部

先确认是哪种原因

  1. 看 structure.json 里选的模板。如果是带腿或带底座的模板，就是模板选错了：这类软包圆墩是"实心旋转体"，没有腿。
  2. 把地面裁剪前后的高斯分别渲染一张侧视图，看侧壁最下面几厘米是否被裁掉了。
  3. 在第 02 节的体素网格里看侧壁贴地段的占据状态。如果是占据，而模型在那里内缩，说明拟合没有受到"覆盖占据"的约束。

修订规则

  • 地面裁剪只裁真正在地面以下的部分。以地面平面为基准，裁掉中心低于 floor − 5 mm 的高斯，不要向上留余量。地面平面本身要用大范围的地面高斯拟合，不要只用物体附近一小块。
  • 接触面封口的唯一形式：把与地面相交的侧壁沿竖直方向延伸到地面平面，再用平面截断并封口。封口面的轮廓就是侧壁在地面处的截面。不允许在接触面生成任何独立部件或内缩台阶。
  • 模板部件要有证据。模板里的可选部件（底座、横撑、底板、腿）只有在对应区域有占据证据时才能启用。未知区域里不允许启用可选部件；完全看不到的结构，按最简单的形状处理。
  • 补充模板 solid_revolution：输入是一条母线（径向轮廓），绕竖直轴旋转生成实体。软包圆墩、花盆、垃圾桶、圆柱靠垫都用它。母线从体素网格里取：把占据和未知体素按到轴的距离和高度投到 (r, z) 平面，取每个高度上的外边界，再做平滑。这样贴地处的轮廓由观测决定，不由模板猜。
近地段轮廓为什么会不一样贴地的那一段在原高斯里通常有比较重的阴影，而且被地面高斯包围，分割和裁剪都容易出错。用母线从体素里取轮廓之后，只要侧壁的占据证据还在，轮廓就会一直延伸到地面。

05H 底座桌：开口与异物

桌角开口：残差特征切割

参数化模板不可能把所有缺口、开孔都预先做成参数。做法是先拟合基本模板，再用"空 ∩ S"的残差团生成切割体，用布尔运算减掉。

S0 = 拟合基本模板（矩形桌面 + 立柱 + H 底座）
for 每个 (空 ∩ S0) 残差团 R（体积 > 2 cm³）:
    在 R 所在部件的局部坐标系中拟合切割体：
        长方体 / 圆柱 / 圆角槽，选择 IoU 最高的
    切割体沿部件厚度方向延伸贯穿（缺口、开孔都是贯穿的）
    S = manifold3d.difference(S, 切割体)
检查切割后 (占据 \ S) 没有变多；变多说明切错了，撤销这一刀
  • 切割结果附带多视角渲染图，残差区域高亮，交给 GPT 确认"这里是否确实是开口"。GPT 判断为否时，保留体素证据，转人工复核，不自动撤销。体素证据优先于 GPT 的判断。
  • 小于约 1.5 cm 的开孔（比如提手孔）受高斯分辨率限制，证据通常不足。这类细节先接受丢失，在质检报告中标出。

遥控器：支撑面异物剔除

理想情况是实例拆分阶段就把遥控器拆成独立实例。在单物体流水线里，再加一道保险：

  1. 拟合出桌面的顶平面后，找出位于顶平面上方 3 mm 以上、在桌面投影范围内的高斯。
  2. 对它们做连通聚类，并和桌面颜色比较（Lab 空间 ΔE）。高出桌面、自成一团、颜色明显不同的，判为异物。
  3. 从物体高斯中移除异物，交还场景作为一个新的待拆分实例。
  4. 异物底下的那块桌面在体素网格里标为未知，不是空，也不是占据。几何由模板的平面桌面决定，纹理由同材质区域补色（第 07 节）。

之所以还留下黑块和鼓包，是因为遥控器的高斯既参与了几何拟合，又参与了取色。剔除之后，这两个问题会一起消失。

06躺椅：无模板物体

v0.7 的路线 D（可信点加 Screened Poisson 加裁剪）有两个问题：可信点一稀疏就出洞，裁剪又会制造更多的洞。替换为下面两条路线，二者都在体素上构造实体，从体素实体提取的等值面必然是水密的。

D1　剖面扫掠（躺椅优先走这条）

很多软装家具沿某个方向截面基本不变：沙发、躺椅、长凳、长条靠垫。截图里的躺椅就是一个 V 形截面沿宽度方向拉伸出来的形状。

  1. 找拉伸轴：对占据体素做 PCA，候选轴取三个主轴，选使截面变化最小的那个（相邻截面的 IoU 最高）。
  2. 求剖面：沿拉伸轴把体素切成片，每片得到一张 2D 状态图。对所有切片按"占据优先、空排除、未知由多数决定"取稳健剖面，相当于跨切片投票。被遮挡的切片会被其他切片补上。
  3. 剖面轮廓提取后简化成多边形，用 Blender 拉伸到实际宽度，两端按观测到的端面形状收圆角（Bevel）。
  4. 拟合判据：拉伸体与占据体素的覆盖率 ≥ 95%，侵占空体素 ≤ 1%。不满足说明物体不是拉伸体，进入 D2。

D2　体素雕刻（通用兜底）

solid = (state != 空) ∩ (地面以上) ∩ (包围盒内)      # 未知先当作实体：保守估计
solid = 对称补全(solid)                              # 有对称时，第 02 节
solid = 最大连通分量(solid)
solid = 形态学闭运算(solid, 半径 2 体素)              # 去小孔
mesh  = marching_cubes(高斯平滑(solid, σ=1 体素), 0.5)  # 水密
mesh  = Taubin 平滑 → 减面
mesh  = 收缩包裹：可信区域的顶点吸附到观测表面（Blender Shrinkwrap，限定顶点组）
  • 未知先当实体是保守做法，代价是被遮挡的凹面可能被填满，比如躺椅 V 形内侧如果完全没看到，会被填平。剖面扫掠（D1）没有这个问题，所以 D1 优先。
  • 收缩包裹只作用于可信点覆盖的区域，并限制最大位移 1 cm，避免重新把凹陷拉回来。
  • 软包表面的褶皱、绗缝不要放进几何，烘焙成法线贴图。仿真用的碰撞体本来就用简化形状。

07纹理补充

  • 取色只用贴在最终表面上的高斯。直接取色时，只用离最终 mesh 表面 1 cm 以内、且不属于异物的高斯。遥控器剔除后，桌面中间的黑块就不会被取进来。
  • 未知区域不取观测颜色。异物底下、贴地底面、遮挡区域，一律按同材质区域补色：在 UV 空间里用周边同材质纹理做修补（OpenCV inpaint，按 UV 岛分别处理），或者直接用材质区平均色。圆凳底部发黑，大概率是取到了贴地的阴影色，也按这条处理。
  • 阴影带。贴地 2–3 cm 的侧壁通常有接触阴影，在去光照步骤里单独加一道：对该高度带内的亮度，用上方相邻带的亮度做比例校正。

08门禁必须强制执行

躺椅带着大量孔洞走到了输出，说明 G4 门禁在实现里没有生效，或者失败后没有阻断。门禁要做成流水线的硬性步骤：不通过就停在当前阶段，写明原因，进入修复或人工队列。

指标阈值说明
边界边数量= 0水密的直接判据（trimesh is_watertight）
非流形边、自交= 0manifold3d 能成功构造即通过
连通分量数= 结构描述中的预期值通常为 1
亏格= 预期值由结构描述和切割数推算；对开孔、把手敏感
占据覆盖率≥ 97%新增；对应约束"覆盖占据"
空体素侵占≤ 0.5% 且无 > 2 cm³ 的团新增；对应约束"排除空"，能抓住被补平的开口
可信点距离 P95≤ 8 mm沿用 v0.7

v0.7 的"轮廓 IoU 平均值 ≥ 0.92"保留，但不再作为主要判据。它是全局平均值，对局部缺口和小部件不敏感，H 底座桌就是这样通过的。

09实验清单 F1–F9

以这三个样本作为本轮的回归集，再加上 v0.7 测试集中的其他物体。每项实验都输出前后对比的多视角渲染拼图。

F1
门禁接入

在输出前强制运行第 08 节的拓扑检查，确认躺椅当前结果会被拦下。

这一步最先做。它不改善效果，但能防止坏结果被当成好结果。

F2
三态体素网格

对三个样本计算空间三态证据，输出切片图（水平切片和竖直切片，三种颜色）。

判据：桌角开口处是空；遥控器后方和贴地底面是未知；圆凳侧壁贴地段是占据。三条都对，后续步骤才有意义。

F3
可信相机区域

对比"全球面相机"和"限定采集区域相机"两种设置下空体素的分布。

预期：全球面设置会在底部和背面产生伪造的空体素。

F4
圆凳原因定位

按第 04 节的三步检查，确定是模板错误、地面裁剪过度还是阴影误判。

F5
圆凳改用 solid_revolution

母线取自体素，接触面按新规则封口。

判据：近地段轮廓与原高斯侧视渲染一致（轮廓误差 ≤ 5 mm），底部无台阶。

F6
桌子异物剔除

检测并移除遥控器高斯，重跑拟合和取色。

判据：桌面平整，无黑块。

F7
桌子残差切割

拟合中加入空体素项，提取残差团并生成切割体。

判据：右上角开口恢复，空体素侵占无 > 2 cm³ 的团。

F8
躺椅剖面扫掠

D1 路线：找拉伸轴、跨切片投票求剖面、拉伸、倒圆角。

判据：水密，占据覆盖 ≥ 95%，V 形内侧保持开口。

F9
躺椅体素雕刻对照

D2 路线跑同一个样本，与 F8 对比。

用于确认 D1 失败时 D2 的兜底效果。
