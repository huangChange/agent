单物体流水线调试方案

v0.6 方案落地后，形状补全和纹理两块效果不达预期：凳子类物体补全后仍有凹陷，纹理在不同面上颜色不一致。本文分析根因，修订单物体流水线的设计原则和各阶段做法，并给出可以在内部数据上逐项验证的实验清单。目标是先让单物体流水线在一个固定测试集上稳定产出合格结果，再扩展到其他类别和场景级流程。

几何：凹陷是错误观测，不是缺失原方案假设"观测到的都可信"。凹陷区域有数据但数据错了，补全不会处理它，形变还会把好的模板拉进坑里。修订后引入逐区域置信度，可疑观测按缺失处理。
规则物体以参数化结果为准凳子、桌子、柜子这类物体，观测数据只用来拟合尺寸参数，最终几何直接用参数化模型，不再做非刚性形变。仿真要的是干净和尺寸正确。
纹理：只用视角无关的颜色3DGS 的高阶球谐系数编码的是视角相关颜色，按视角烘焙就会出现正面和侧面不同色。修订后只用 0 阶（DC）颜色，加多视角加权融合和按材质区域去光照。

02修订后的设计原则

v0.6 的核心原则是"观测区域信观测，缺失区域按结构补全"。实践表明，这条原则在数据有瑕疵时不成立。修订为以下四条。

  1. 观测分三态：可信、可疑、缺失。每个表面区域都要先算置信度，再决定信不信。只有可信观测参与约束最终几何；可疑观测和缺失区域一样，交给结构先验补全。
  2. 规则物体以结构先验为主，观测为辅。对家具、器物这类规则几何，最终 mesh 直接用参数化模型，观测数据只负责确定参数（尺寸、位置、倾角、圆角）。不做逐顶点的非刚性形变。对仿真来说，一个尺寸正确的干净凳子比一个忠实保留凹陷的凳子更有用。
  3. 观测与先验冲突时，以多数证据为准。对称副本之间、多个视角之间、高斯与 SLAM mesh 之间互相投票。单一来源的异常观测不能决定几何。
  4. 颜色只用视角无关的部分。纹理只从球谐 0 阶颜色取色；视角相关的部分在仿真资产里没有对应物，应该丢弃。
"忠实"和"正确"的取舍扫描重建追求忠实于数据；仿真资产追求物理上正确。本流水线的验收标准是后者：尺寸误差小、水密、结构合理、外观一致。凡是二者冲突的地方，按正确处理。

04阶段 2a　物体高斯清理

后续所有几何和纹理都来自这一步的输出，这一步的错误会一路传下去。重点检查以下四项。

1. 参数激活（最常见的隐蔽 bug）

Inria 3DGS 的 PLY 文件存的是激活前的原始值：不透明度是 logit，尺度是 log，四元数未归一化，颜色是球谐系数而不是 RGB。gsplat 等渲染器要求传入激活后的值。漏掉任何一项，渲染结果看起来"差不多"，但深度和不透明度都是错的。

# Inria PLY → 渲染器输入
opacity = sigmoid(ply["opacity"])                 # logit → [0,1]
scales  = exp(stack(ply["scale_0..2"]))           # log → 米
quats   = normalize(stack(ply["rot_0..3"]))       # 顺序为 wxyz
sh_dc   = stack(ply["f_dc_0..2"])                 # [N,3]
sh_rest = ply["f_rest_*"].reshape(N, 3, -1).transpose(0, 2, 1)   # 注意：按通道存储，需转置
rgb_dc  = clip(0.5 + 0.28209479 * sh_dc, 0, 1)    # DC 颜色，纹理阶段用

2. 去除漂浮物和噪声高斯

  • 不透明度过滤：去掉 opacity < 0.05 的高斯（阈值按数据调整）。
  • 尺度过滤：去掉最大轴超过物体包围盒对角线 10% 的超大高斯，以及三轴都极小且不透明度低的噪点。
  • 统计离群：对高斯中心做半径或 KNN 离群检测（Open3D remove_statistical_outlier）。
  • 连通性：按中心点做 DBSCAN 聚类，只保留主簇和与主簇距离很近的小簇。凳子腿细，聚类半径不要设得太小，否则会把腿切掉。

3. 边界回收

分割在物体与遮挡物、地面接触处常常切得过狠，留下一个坑。在物体包围盒外扩 3–5 cm 的范围内，从原场景高斯里回收满足以下条件的高斯：

  • 不属于任何其他实例；
  • 中心离物体高斯表面距离小于 1–2 cm；
  • DC 颜色与邻近物体高斯接近（Lab 空间 ΔE 在阈值内）；
  • 不在检测到的地面或墙面平面上（避免把地面收进来）。

回收的高斯打上 recovered 标记，置信度阶段给它较低的初始权重。

4. 支撑面

用 SLAM mesh 或场景高斯拟合地面和墙面平面（RANSAC），把物体底部低于地面的高斯裁掉。这个平面后面用于接触面封口和尺度校验。

05阶段 2b　观测几何提取

目的是得到一份宁缺毋滥的观测点云：宁可少一些点、留下洞，也不要有错误的点。洞会被补全阶段处理，错误的点会污染后续每一步。

虚拟相机布置

  • 以物体包围盒中心为球心，按斐波那契球面均匀取 100–200 个视角，取 2 个半径（包围盒半径的 1.8 倍和 2.5 倍）。
  • 去掉相机位于地面以下、墙内或被其他实例完全挡住的视角（物体是从场景中抠出来渲染的，但这些视角对应的表面在原场景里不可能被观测到）。
  • 保存每个视角的内外参，后续置信度和纹理都要复用。

渲染：深度和 alpha 一起用

# gsplat 示例：sh_degree=0 只用 DC 颜色；RGB+ED 同时输出颜色和期望深度
render, alpha, _ = gsplat.rasterization(
    means, quats, scales, opacity, colors=sh_all,     # sh_all: [N, K, 3]
    viewmats=V, Ks=K, width=W, height=H,
    sh_degree=0, render_mode="RGB+ED")
rgb, depth = render[..., :3], render[..., 3]
valid = alpha[..., 0] > 0.95                          # 半透明像素不可信，丢弃
  • alpha 阈值是治凹陷的第一道关。alpha 低于 0.95 的像素，深度是前后表面的混合值，直接丢弃。可以从 0.9、0.95、0.98 三档做对比实验（第 12 节 E2）。
  • 深度边缘腐蚀。对有效掩码做 2–3 像素腐蚀，去掉轮廓处的混合深度。
  • 如果所用渲染器支持中位深度（累计透射率首次低于 0.5 处的深度），优先用中位深度，它对半透明高斯更稳健。不支持时用 ED 加 alpha 阈值加下面的一致性过滤代替。

多视角一致性过滤

这是多视角立体（MVS）里常用的深度融合方法，用来去掉只在少数视角出现的错误深度：

for 每个视角 i 的每个有效像素 p:
    X = 反投影(p, depth_i[p])
    n_agree = 0
    for 邻近视角 j（光轴夹角 10°–60°）:
        q, z = 投影(X, j)
        if valid_j[q] and |depth_j[q] - z| / z < 0.01:
            n_agree += 1
    保留 p 当且仅当 n_agree >= 3

通过过滤的像素反投影成点云，法线用深度图梯度或该处主导高斯的最短轴方向。最后按 2–5 mm 体素下采样。

是否还需要 TSDF

TSDF 融合仍然可以用（Open3D ScalableTSDFVolume），但它的输出只用于可视化和兜底路线 D。主路线不再把 TSDF mesh 当作观测几何的载体，原因是 TSDF 会把错误深度平均进表面，而且会把未观测区域闭合成一个看似合理的面，掩盖缺失。主路线只用过滤后的点云。

辅助观测源

  • 高斯中心点云：取不透明度高、形状扁平（最短轴远小于其余两轴）的高斯，中心作为点，最短轴作为法线。它不依赖渲染，可以和深度点云互相校验。
  • SLAM mesh：在物体包围盒内裁剪出来，作为第三个观测源参与置信度投票，不直接进入几何。

06阶段 2c　观测置信度

这是本次修订新增的核心阶段。对观测点云的每个点算一个 0 到 1 的置信度，然后分成三态。

置信度的组成

分项计算方式防的是什么
覆盖度 cview该点在多少个视角中可见且通过一致性过滤，并按入射角余弦加权；归一化到 [0,1]只被掠射角或单一视角看到的点
密度 cgs该点邻域内高斯的不透明度之和，相对物体整体中位数归一化稀疏、半透明区域产生的错误表面
SLAM 一致性 cslam到 SLAM mesh 的距离，小于 1 cm 记 1，大于 3 cm 记 0，中间线性；SLAM 没覆盖处记 0.5高斯本身的几何偏差
对称一致性 csym对称变换后，在对称副本位置附近是否有吻合的观测（第 08 节）；无对称时记 0.5单侧的凹陷、鼓包
来源 csrc原始物体高斯记 1，边界回收的高斯记 0.6回收错误
 
conf = c_view^0.3 · c_gs^0.2 · c_slam^0.2 · c_sym^0.3 · c_src      # 加权几何平均：任一项很低都会拉低总分

可信：conf >= 0.6      可疑：0.3 <= conf < 0.6      缺失：没有观测点（由覆盖图确定）

权重和阈值是初始值，需要在测试集上校准。校准方法：在 5–10 个物体上人工标注凹陷区域，调整权重使凹陷点大多落入"可疑"、正常表面大多落入"可信"。

可视化

每个物体输出一张置信度热力图（点云按置信度着色，多视角渲染拼图）。调试时先看这张图：如果凹陷区域不是红色，后面的补全就不可能修好它，问题在这一阶段。

07阶段 3a　结构理解

由 gpt-6-astra 看多视角渲染图，输出结构化的物体描述。和 v0.6 的区别是：GPT 只负责描述结构，不直接写最终建模代码。建模代码由我们自己的参数化工具库生成，GPT 选模板、填初值。这样输出稳定、可校验，参数的精确值由拟合阶段决定。

输入

  • 6–12 张 DC 颜色渲染图（正视、侧视、俯视、45° 斜视），附带比例尺和包围盒尺寸（米）。
  • 一张置信度热力图，提示哪些区域的观测不可信，避免 GPT 把凹陷当成设计特征。

输出 schema（示例：凳子）

{
  "category": "stool",
  "template": "round_seat_n_legs",            // 必须是模板库中已有的模板
  "symmetry": { "type": "rotational", "order": 4, "axis_hint": "vertical" },
  "contact": ["floor"],
  "parts": [
    { "name": "seat", "shape": "cylinder", "init": { "radius": 0.17, "thickness": 0.03 } },
    { "name": "leg",  "shape": "tapered_cylinder", "count": 4,
      "init": { "r_top": 0.015, "r_bottom": 0.012, "splay_deg": 8 } },
    { "name": "stretcher", "shape": "ring", "optional": true }
  ],
  "materials": [ { "parts": ["seat"], "kind": "wood" }, { "parts": ["leg", "stretcher"], "kind": "wood" } ],
  "suspect_regions": ["seat top, one side, looks dented — likely occlusion artifact"]
}
  • 用 JSON Schema 校验输出，不合规就带着错误信息重试，最多 2 次。
  • 同一物体调用 3 次（不同视角子集），模板和对称阶数取多数票；不一致时转人工或走兜底路线。
  • 模板库从高频类别开始建：方凳、圆凳、四腿椅、方桌、圆桌、箱体柜、圆柱或旋转体容器。每个模板是一个 Python 函数，输入参数字典，输出水密 mesh（用 manifold3d 布尔运算拼部件，保证水密）。

08阶段 3b　形状补全

四条路线按顺序尝试。前一条能给出完整、通过门禁的形状，就不进入下一条。

路线适用做法稳定性
A 接触面封口所有贴地、贴墙的物体（与其他路线叠加）沿支撑面平面截断并封口高
B 对称投票有镜像或旋转对称、但不适合参数化的物体（异形花瓶、雕花椅背）拟合对称轴，所有对称副本投票重建表面较高
C 参数化模板规则家具、器物：凳、桌、椅、柜、杯、盆模板 + 参数拟合，最终几何即模板输出高
D 兜底重建无对称、无模板的物体（软装、植物）带置信度权重的 Screened Poisson，只用可信点中

路线 B：对称投票

v0.6 的对称补全是"镜像观测侧到缺失侧"。修订为对称副本之间投票，凹陷会被其他副本的正常观测投掉。

# 1. 对称轴拟合：GPT 给出对称类型和轴的初值，再用 ICP 精修
#    目标：min Σ_可信点 dist(T_k(p), obs_points)，T_k 为第 k 个对称变换
# 2. 投票：把所有点变换到"基本域"（例如 4 阶旋转对称取 0°–90° 扇区）
pooled = concat([T_k_inv(obs_points) for k in range(order)])
# 3. 在基本域内按体素或径向射线分组，每组取置信度加权的稳健值
#    对外表面：沿法线方向取加权中位数（凹陷是少数派，会被投掉）
# 4. 把基本域结果再按对称变换复制回完整物体，重建表面

注意事项：对称轴误差会让投票结果变模糊，轴拟合精度要在 1–2 mm 和 0.5° 以内；真实存在的不对称结构（比如单侧的把手）要由结构描述标出并排除在投票之外。

路线 C：参数化模板（凳子推荐路线）

  1. 按 structure.json 选模板，填入 GPT 给的初值。
  2. 用对称轴和支撑面确定模板的位置和朝向：凳子竖直轴等于旋转对称轴，腿底落在地面平面上。
  3. 进入阶段 4 做参数拟合。
  4. 拟合后的模板输出就是最终几何，不再向观测点做逐顶点形变。

这条路线对凹陷天然免疫：凹陷区域的点在拟合中被稳健损失降权（第 09 节），而模板本身不可能产生凹陷。

路线 D：兜底重建

  • 只用可信点，以置信度为权重做 Screened Poisson（PyMeshLab），深度 8–10。
  • 用观测覆盖图裁掉远离可信点的面片，再用 Blender 的 voxel remesh 加小洞填充得到水密结果。
  • 这条路线的结果默认进人工复核队列，不自动通过。

09阶段 4　拟合与网格化

参数拟合

模板参数通常只有 5–20 个，用无梯度优化（CMA-ES）即可，不需要可微渲染。目标函数由三项组成：

L(θ) = w1 · Σ_{p∈可信点} conf_p · ρ( dist(p, M(θ)) )         # 观测 → 模型 的单向距离
     + w2 · Σ_{视角 v} (1 - IoU( sil(M(θ), v), mask_v ))      # 轮廓一致
     + w3 · R(θ)                                             # 先验：对称、腿等长、尺寸在常识范围内

ρ(d) = min(d², τ²)，τ ≈ 1.5 cm       # 截断损失：离模型太远的点视为离群，不再拉动模型
  • 单向距离。只算"观测点到模型"的距离，不算"模型到观测点"。缺失区域没有观测点，不应该把模型往任何方向拉。
  • 轮廓项对凹陷不敏感。表面凹陷通常不改变外轮廓，所以轮廓 IoU 能稳定约束整体尺寸。轮廓用 alpha 掩码（阈值 0.5，比深度阈值宽松）。只用覆盖度高的视角。
  • 点到模型的距离用 trimesh 或 Open3D RaycastingScene 计算；轮廓用 Open3D 光线投射或简单的 mesh 光栅化生成，每次评估在毫秒级。
  • CMA-ES 用 cma 库，种群 16–32，迭代 100–300 次，一个物体在 CPU 上几十秒到几分钟。

非刚性形变（只用于路线 B、D）

路线 C 不做形变。路线 B、D 如果需要把候选形状贴近观测，用 ARAP 形变（libigl），并满足：

  • 只有可信点作为目标约束，且约束点到候选面的距离小于 τ 才生效；
  • 形变后与候选形状的最大偏差不超过 1 cm，超过说明候选形状本身不对，应退回补全阶段，而不是硬拉。

网格化与清理（Blender 无界面脚本）

  • 模板输出用 manifold3d 合并部件，保证水密、无自交。
  • 减面到目标面数（仿真视觉网格建议 5k–30k 三角面），保留尖锐边。
  • UV 展开：规则物体用 Blender Smart UV Project，或者 xatlas；按部件分 UV 岛，便于纹理阶段按材质区处理。UV 岛间距至少 4 像素（按 2048 贴图计）。
  • 规范坐标：Z 轴向上，原点在底面中心，单位米。

10阶段 5　纹理与贴图

没有原始照片时，颜色只能从高斯取。高斯颜色里混着视角相关效应和场景光照，纹理阶段的工作就是把这两部分尽量去掉，得到一张视角无关、光照均匀、无接缝的 basecolor 贴图。

第一步：只用 DC 颜色

球谐 0 阶系数对应视角无关的平均颜色，1–3 阶对应随视角变化的部分（高光、反射）。正面和侧面颜色不同，大概率就是高阶项造成的。做法：渲染烘焙图时设 sh_degree=0，或者把 f_rest 全部置零。这一项改动小、收益大，建议最先做（第 12 节 E1）。

第二步：取色到纹素，两种方法

方法做法优点缺点
直接取色（推荐先做）对每个纹素求其 3D 位置，用 KD 树找附近 K 个高斯，按 opacity × exp(-d²/2σ²) 加权平均 DC 颜色完全视角无关，没有接缝，实现简单细节受高斯密度限制，偏糊
多视角投影每个纹素投影到所有可见视角，按 cos(θ)^4 × 覆盖度 加权平均（θ 为视线与法线夹角，大于 70° 的视角不用），用深度图做遮挡检测细节更清楚需要调平接缝

两者可以组合：直接取色作为低频底色，多视角投影的高频细节（原图减去其高斯模糊）叠加上去。这样底色稳定，细节也保留。

补全区域的颜色：参数化模型和对称补全生成的表面没有观测颜色。按优先级：取对称副本对应位置的颜色；没有对称则取同材质区域的平均色加轻微噪声纹理；不要从边缘拉伸像素。

第三步：接缝和色彩调平

  • 使用多视角投影时，加全局色彩调平（Lempitsky & Ivanov 2007，mvs-texturing 中有实现）：对每个视角块求一个平滑的颜色偏移，使接缝两侧颜色连续。
  • UV 岛边缘向外扩 8–16 像素（dilation），避免 mipmap 采样时露出背景色。

第四步：按材质区域去光照

3DGS 颜色本身包含阴影、AO 和环境光，完全去除需要原始照片和光照估计，这里做一个对仿真足够的近似：

  1. 材质分区。按结构描述里的部件和材质标注划分区域；同一部件内再按 Lab 颜色做 K-means（K=1–3），分出真正不同的材质（比如凳面的漆面和边缘的原木）。
  2. 估计低频光照。在每个区域内，对亮度通道 L 做大尺度平滑（在网格表面上按测地距离平滑，或在纹理空间按 UV 岛分别做高斯模糊），得到低频光照场 S。
  3. 去除。L_albedo = L / S × mean(L)，只修改亮度，色度 a、b 不动。阴影、明暗面被拉平，木纹等高频细节保留。
  4. AO 补偿（可选）。用 Blender 烘焙几何 AO，在 AO 很暗的区域（凳腿与座面的交角）适当提亮。
预期效果的边界这个近似能消掉大面积的阴影和明暗面差异，但处理不了强烈的投射阴影边界和彩色环境反射。这些情况用材质区平均色替换局部区域更稳妥，并在质检报告中标出。

第五步：材质参数与导出

  • basecolor 贴图 2048²，sRGB 色彩空间，PNG 或 KTX2。
  • roughness、metallic 先按材质类别给常数（木头 0.6 / 0，金属 0.35 / 1，塑料 0.45 / 0），为后续 PBR 预留。
  • 生成 mipmap，导出 GLB 时检查贴图色彩空间标记。

阈值是建议初值，需要在测试集上校准。所有指标进入每个物体的质检报告。

12调试方法与实验清单

调试方法

  1. 固定测试集。选 8–12 个物体：3–4 个凳子和椅子（含目前效果差的那个凳子）、2 个桌子、2 个柜子、2 个容器、1 个无对称物体。整个调试周期内不更换，每次改动都在全集上跑。
  2. 人工遮挡测试。从测试集中挑 3 个数据质量好的物体，人为删掉一侧 20%–40% 的高斯，或者在一侧降低高斯不透明度制造凹陷。原物体作为真值，算 Chamfer 距离和体积 IoU。这是唯一能定量回答"补全补得对不对"的办法。
  3. 逐阶段落盘与可视化。每个阶段输出固定视角（6 个）的渲染拼图，文件名带阶段编号。凹陷出现时，从前往后翻拼图，找到它第一次出现的阶段。
  4. 一次只改一个变量。每次实验记录配置哈希、代码版本和指标，结果写入表格，便于对比。

实验清单（按建议执行顺序）

E0
核对参数激活

检查 PLY 读入后不透明度、尺度、四元数是否激活，f_rest 是否正确转置。用激活前后的数值分布直方图确认。

判据：opacity 在 [0,1]，scale 量级为毫米到厘米。这一项错了，后面的实验都没有意义。

E1
DC 颜色 vs 完整球谐

同一物体分别用 sh_degree=0 和 3 渲染 12 个视角，比较同一表面在不同视角的颜色差。

预期：DC 渲染下正面和侧面颜色差明显缩小。若改善明显，纹理阶段直接切换到 DC。

E2
alpha 阈值扫描

alpha 阈值取 0（不过滤）、0.9、0.95、0.98，分别融合点云，对比凹陷区域的点。

预期：阈值提高后凹陷区域的点明显变少，变成洞。若凹陷仍在，说明错误几何来自高不透明度的高斯，查 E3。

E3
多视角一致性过滤开关

在 E2 选定的阈值上，开关一致性过滤，对比点云和凹陷区域。

预期：凹陷区域的残留点被大量过滤。

E4
凹陷来源定位

把凹陷区域的点反查到对应高斯，看它们的不透明度、尺度、是否靠近分割边界，并在原场景高斯中查看同一区域。

若原场景中该区域完整、物体高斯中缺失，问题在分割，做边界回收；若原场景中也凹陷，问题在原始重建，只能靠先验补全。

E5
置信度热力图

实现第 06 节的置信度，人工检查凹陷区域是否被标成可疑。

判据：人工标注的凹陷点中 80% 以上落入可疑，正常表面点中 90% 以上落入可信。

E6
凳子走参数化路线

手写一个圆凳或方凳模板，用 GPT 结构描述加 CMA-ES 拟合，不做形变。

判据：G4 全部通过，凹陷检测为 0，尺寸偏差 ≤ 2%。这是本轮调试的里程碑。

E7
形变开关对比

同一物体分别输出"拟合后不形变"和"拟合后 ARAP 形变"，比较凹陷检测和可信点距离。

用于确认形变是否在把模型拉进凹陷；若是，规则物体关闭形变。

E8
取色方法对比

直接取色、多视角投影、两者组合三种方式，比较跨视角 ΔE 和接缝 ΔE，并肉眼看清晰度。

E9
去光照前后对比

同一物体去光照前后的贴图、材质区亮度方差、多视角渲染拼图。

14调试排期

按一人全职估算。每周末在固定测试集上跑全量，指标写入对比表。

第 1 周纹理快修与观测
  • E0、E1：参数激活核对，纹理切换到 DC 颜色。
  • E2、E3：alpha 阈值和多视角一致性过滤，观测点云替代 TSDF。
  • 搭好逐阶段可视化和人工遮挡测试。
第 2 周置信度与凳子
  • E4：凹陷来源定位，按结果决定是否做边界回收。
  • E5：置信度三态，校准权重。
  • E6：凳子参数化模板跑通，达到第一个里程碑。
第 3 周对称投票与模板扩充
  • 路线 B 对称投票，在椅子和花盆上验证。
  • E7：确认规则物体关闭形变。
  • 模板扩充到桌子、柜子、容器。
第 4 周纹理完善与稳定性
  • E8、E9：取色方法定型，去光照和补全区补色。
  • 门禁阈值校准，测试集全量通过率作为验收指标。
  • 失败样本归类，更新诊断手册。
本轮验收标准固定测试集中，规则物体（凳、桌、柜、容器）G4、G5 门禁通过率达到 80% 以上；凳子样本无可见凹陷，多视角渲染无明显色差。达标后再推进实例拆分、场景级编排和 agent 修复回路。
